How to Write an ATS-Friendly CV in Nigeria (Free Template)

September 2026 · 6 min read

An Applicant Tracking System (ATS) is software that many mid-size and large employers use to scan, sort, and sometimes automatically filter CVs before a human ever opens them. If a CV is formatted in a way the software can't parse cleanly, a genuinely qualified candidate can be filtered out before anyone reads a word of it. The fix isn't complicated — it's mostly about formatting discipline, not clever tricks.

Key takeaways
  • ATS software reads text, not design — heavy graphics, tables, columns, and text boxes often parse incorrectly or get skipped entirely.
  • Standard section headings (Experience, Education, Skills) are read correctly; creative renamed headings often aren't.
  • Match the exact keywords from the job description where genuinely true of your experience — ATS systems frequently rank by keyword match.
  • A simple single-column layout, saved as PDF or Word, is the safest format across most systems.

What actually trips up an ATS

  • Multi-column layouts. Some systems read left-to-right across the whole page, scrambling a two-column CV's text order into nonsense.
  • Text inside images or graphics. If your contact details or a skills chart are part of an image rather than real text, the system can't read them at all.
  • Tables. Some ATS software handles tables fine; others don't extract the content correctly, especially with merged cells.
  • Unusual section headings. "My Journey" instead of "Experience," or "What I Bring" instead of "Skills," can go unrecognized by systems looking for standard section names.
  • Headers/footers for key info. Contact details placed in a page header or footer are sometimes skipped entirely by parsing software.

What to do instead

  • Use a single-column layout with your name and contact details in the main body, not a header/footer.
  • Use standard section headings: Summary, Experience, Education, Skills, Certifications.
  • List work experience with plain text and simple bullet points, not tables or graphics.
  • Save as PDF unless the job posting specifically asks for Word — most modern systems parse PDFs correctly, and PDF preserves your formatting exactly as designed.

Matching keywords without overdoing it

Many ATS platforms rank or filter candidates partly by how closely their CV's language matches the job description's keywords. If a posting asks for "stakeholder management" and that's genuinely part of what you did, use that exact phrase rather than only a rough synonym like "worked with people across departments." This isn't about gaming the system — it's about describing real experience in the same language the employer used to describe the role.

One thing to avoid: stuffing invisible or irrelevant keywords (e.g., in white text, or a long unrelated skills list) to try to trick the score. Most modern ATS platforms and the recruiters reviewing the shortlist both catch this, and it can cost you credibility once a human does read it.

For Nigerian job seekers specifically

Many roles advertised by larger Nigerian employers, multinationals with a Nigerian office, and remote/international roles that accept Nigerian applicants do run CVs through an ATS before a recruiter sees them. Smaller local businesses more often review CVs manually — in that case, ATS formatting matters less, but a clean, standard layout still reads well to a human reviewer too, so there's little downside to using it as your default format either way.

Frequently asked questions

Should I use a two-column CV at all?
It's a tradeoff — two-column layouts often look more visually polished but carry more ATS risk. If you know a specific employer reviews CVs manually rather than through software, it's a safer choice; for a broad application round with larger companies, single-column is the lower-risk default.

Is PDF or Word safer for ATS systems?
PDF is generally safe with modern ATS software and preserves your exact formatting. Only switch to Word if a specific job posting explicitly requests it.
